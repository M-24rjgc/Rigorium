# Rigorium Brand Proposal

## Name

**Rigorium** combines "rigor" with the suffix "-ium", framing the product as a durable place for rigorous inquiry rather than a tool for one research task.

Descriptor: **Personal research workspace**

## Mark

The mark uses an `R` as a stable frame and a connected path as the research trace. The three nodes represent a question, evidence, and a defensible result. The mark avoids field-specific symbols so it can cover literature, experiments, data, writing, and general project work.
